# SaaS Manual QA Testing Project

## Overview

Demonstration manual QA project covering the testing and validation
of a publicly available SaaS web application.

## Testing Scope

- Functional testing
- Regression testing
- End-to-end testing
- Form validation
- Negative testing
- Role and permission testing
- Cross-browser testing
- Usability testing

## Deliverables

- QA Test Plan
- Test Case Suite
- Bug Reports
- Test Execution Results
- Regression Test Suite
- Release Readiness Report

## Tools

- Google Sheets
- Google Docs
- Chrome DevTools
- Postman
- GitHub

## Disclaimer

This is an independent demonstration project created for portfolio
purposes. No proprietary or confidential information from previous
employers has been used.
